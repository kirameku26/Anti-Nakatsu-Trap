# Anti-Nakatsu-Trap

御堂筋線の梅田駅から北へ向かうときに、降りたい駅まで乗り換えなしで行ける列車を確認するサイトです。

[GitHub Pagesでサイトを開く](https://km2.f5.si/Anti-Nakatsu-Trap/)

## 使い方

ページ上部に、梅田発の次の列車で新大阪まで直通できるかを表示します。次が中津行なら、次に乗り換えなしで行ける列車の発車予定時刻も表示します。

新大阪以外へ行くときは、「乗る列車をチェック」で降りたい駅を選び、「直通」と表示された行先をホームの発車案内で探します。

## 時刻表データ

画面の発車時刻は日本時間です。[Osaka Metroの梅田駅時刻表](https://kensaku.osakametro.co.jp/timetable/ja/subway/dia/station/29089/1019/2/) (2025年10月14日現在) と [内閣府の祝日データ](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html) (2025年〜2027年) を `docs/timetable.js` に収録しています。ダイヤ改正時や祝日データの追加時は、このファイルを更新してください。

遅延・運休・臨時ダイヤは、ホームの発車案内やサイト内の公式運行情報で確認してください。

## ローカルで開く

`docs/index.html` をブラウザーで開きます。ビルドや依存パッケージのインストールは不要です。

## 公開サイトを更新する

`docs/` 内のファイルを編集して `main` に反映すると、GitHub Pagesが自動で更新されます。公開元は `main` ブランチの `/docs` です。
